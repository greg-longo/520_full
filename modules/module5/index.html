The vocabulary

matplotlib's vocabulary is small and its error messages assume you know it. The first four entries in particular are worth learning early, because almost every question you ask online will be answered in those words.

  • Figure - The whole image. It owns the figure-level title, the size, and saving to a file.
  • Axes - One plot inside a Figure. It owns the data, the labels, the legend, and the two axis objects. An Axes is not an axis.
  • Axis - A single scale on an Axes, with its ticks, limits and formatting.
  • Artist - Anything matplotlib draws. Every line, dot, label and spine is one.
  • explicit interface - Creating fig, ax and calling methods on them. Also called the object-oriented interface, and the only one this course uses.
  • implicit interface - The plt.plot style, which adds to whatever Axes matplotlib thinks is current. Convenient for one throwaway chart, and the reason a second chart lands in the wrong place.
  • constrained layout - The layout engine requested with layout="constrained", which sizes the gaps so labels do not collide. It replaces tight_layout, and calling tight_layout() switches it off.
  • bin - One interval a histogram counts values into. The bin count is a choice you make, and it changes the shape the reader sees.
  • alpha - Opacity, from 0 to 1. Below 1, overlapping points look darker than single ones, which is how a scatter plot admits that two students landed in the same place.
  • colormap - The mapping from a number to a color. Sequential for ordered values, diverging for a meaningful middle, qualitative for unordered categories.
  • perceptually uniform - A colormap in which equal steps in the data look like equal steps in color. viridis is; jet is not, which is why it invents boundaries the data does not have.
  • colorbar - The key for a colormap. Ask the Figure for it: fig.colorbar(mappable, ax=ax).
  • relative luminance - How bright a color is, and therefore what gray it prints as. Two colors of similar luminance are the same color to a monochrome printer.
  • small multiples - A grid of panels sharing a scale, so several comparisons can be read at once. sharey=True is what makes them comparable.
  • dpi - Dots per inch when a figure is saved as a raster image. 72 is a thumbnail, 150 a document figure, 300 print.
  • raster and vector - Raster formats (PNG) store pixels and blur when enlarged. Vector formats (PDF, SVG) store drawing instructions and do not.
  • axes-level function - A seaborn function that draws onto an Axes you pass with ax=, such as histplot or regplot.
  • figure-level function - A seaborn function that builds its own figure and cannot take ax=, such as pairplot or displot. Customize it through the grid object it returns.
  • truncated axis - A value axis that does not start at zero. On a bar chart, where the reader compares lengths, it misrepresents the comparison.
  • confounder - A third variable that produces an apparent relationship between two others. Faceting or coloring by it is the visual control.

1. Why draw it at all

You can already summarize a column with describe(). So what does a picture add that a table of statistics does not?

The honest answer is a demonstration rather than an argument, and it is nearly fifty years old.

Francis Anscombe published four small datasets in 1973 for exactly this purpose. They are chosen so that the summary statistics a careful analyst would reach for first are, to two decimal places, the same for all four. If those statistics were enough, the four datasets would be interchangeable.

Three things a figure is for

From the course lecture, and worth keeping in this order, because it is also the order the capstone runs in:

PurposeAudienceThe question it answers
Exploreyouwhat is in here that I did not expect?
Explaina colleaguehere is what I found, and why I believe it
Persuadethe Cabinethere is what we should do about it

The same numbers can serve all three, and the figure that serves one badly serves the others worse. An exploratory chart is allowed to be ugly and fast. A chart in a Cabinet report is not.

Which chart answers which question

Choosing a chart type by how it looks, rather than by the structure of the data and the question being asked, is how a figure ends up unreadable. Each type has a job:

ChartUse it whenWhat it showsBuilt in
Histogramone continuous variablethe shape of a distribution: skew, spread, whether there is one hump or twosection 3
Box plotcomparing distributions across categoriesmedian, quartiles and outliers, compactly enough to line several upsections 3 and 5
Scatter plottwo continuous variablesrelationship, clusters and outliers. Color or size can carry a third variablesections 4 and 6
Bar chartcomparing discrete categoriesone value per category, compared by length. Start the axis at zerosection 5
Line chartchange over an ordered variable, usually timetrend and continuity. The line claims the values between the points existsection 9
Heatmapa matrix of valueswhich variables move together, most often a correlation matrixsection 11

Three to be wary of, all of which section 9 takes apart: pie charts, because comparing angles is harder than comparing lengths; three-dimensional charts, where the depth carries no data and distorts the comparison; and dual-axis charts, which let the person drawing them decide how related two series appear.

Figure & Axes

Every figure you make from here on starts with the same line:

fig, ax = plt.subplots()

Two objects come back, and knowing which is which explains most of matplotlib.

fig, ax = plt.subplots(figsize=(5, 3), layout="constrained")

print(type(fig))
print(type(ax))
output

An Axes means a single set of axes, which is one panel of the figure, while an axis is one scale on it. The two words look like a singular and a plural of each other, which is what makes the naming confusing the first time and clear after that.

The practical rule: if it is about the picture, ask the Figure. If it is about the data, ask the Axes.

fig, ax = plt.subplots(figsize=(6, 3.5), layout="constrained")

ax.scatter(cohort.hs_gpa, cohort.ug_gpa, s=26, alpha=0.75)

ax.set_xlabel("high school GPA")          # the Axes owns the labels
ax.set_ylabel("undergraduate GPA")
ax.set_title("One Axes, one claim")
fig.suptitle("The Figure owns this line", fontsize=10)  # and the Figure the frame
output
Text(0.5, 0.98, 'The Figure owns this line')

The other interface, once

matplotlib has a second way to draw the same figure, and you will meet it constantly, so it is worth seeing exactly once.

The implicit interface, also called the pyplot interface, keeps track of the last figure and axes you touched and adds things to whatever it thinks you meant. The explicit interface, the one this module uses, hands you the objects and makes you name them.

Here is one figure, drawn both ways.

# implicit: no objects are named, and there is no way to refer back
plt.plot([1, 2, 3, 4])
plt.ylabel("some numbers")
output
Text(0, 0.5, 'some numbers') 
# explicit: the same figure, with the objects named
fig, ax = plt.subplots()
ax.plot([1, 2, 3, 4])
ax.set_ylabel("some numbers")
output
Text(0, 0.5, 'some numbers')

Identical output, four lines each. On one plot the difference is preference. Here is where it stops being preference.

Translating between them

You will need to read the implicit form, because most examples online use it. The mapping is nearly mechanical:

ImplicitExplicit
plt.plot(x, y)ax.plot(x, y)
plt.xlabel("t")ax.set_xlabel("t")
plt.title("...")ax.set_title("...")
plt.xlim(0, 10)ax.set_xlim(0, 10)
plt.xticks(pos, labels)ax.set_xticks(pos, labels)
plt.legend()ax.legend()
plt.savefig("f.png")fig.savefig("f.png")

The pattern: a plt. function that sets something becomes ax.set_something. A plt. function that draws something keeps its name and moves onto the Axes.

Why most examples you find will look different

This is worth knowing before you start searching, because it will otherwise read as though the course and the internet disagree.

Around 2021 and 2022 the reference material settled on the explicit interface. matplotlib's own documentation now says:

In general, we suggest using the OO style, particularly for complicated plots, and functions and scripts that are intended to be reused as part of a larger project. However, the pyplot style can be very convenient for quick interactive work.

The tutorial sites largely did not follow. Roughly two thirds of the widely used introductions still lead with the implicit interface, and that includes several whose pages carry a recent update date, because a page can be revised for formatting without its code being modernized. One well known reference site teaches plotting without ever using the words Figure or Axes.

So expect a mismatch, and read it as a historical artifact rather than a disagreement about what is correct. The translation table above is the tool for it.

Two honest notes on our own rule. First, matplotlib suggests the explicit style, which is weaker than a requirement, and the implicit style is genuinely convenient for a throwaway look at something. This module uses the explicit form everywhere anyway, for consistency and because every multi-panel figure needs it. Second, plt.subplots() is itself a pyplot function. "Explicit" does not mean avoiding plt.; it means that once the Figure and Axes exist, you address them by name.

Takeaway

Choosing a bin count honestly

      
There is no correct number, which is exactly why it has to be a deliberate choice rather than a default you never looked at.

      
  • Too few bins and real structure disappears into one block.
  • Too many and sampling noise looks like structure.
  • Look at two or three before you settle, which is what you just did.

      
matplotlib will also compute a bin count for you from the data, using rules that account for both the spread and the sample size.

The boxplot: the same column, compressed

What happened
      
The boxplot is compact and exact about the quartiles, and it is blind to shape. A distribution with two separate humps and a distribution with one can produce very similar boxes. Use the box when you are comparing several groups at once and the shape is not the point. Use the histogram when it is.

Histogram for shape, boxplot for comparison. The boxplot's advantage appears the moment you have four groups to line up, which is section 5. Its cost is that it hides everything the shape would have told you.

Next: Color →

    




      
Color

      
Color is the fastest channel a figure has and the easiest one to misuse. Two questions decide almost every color choice: what kind of variable is being encoded, and who has to read the result.

      
Four kinds of colormap, four kinds of question

      
matplotlib groups its colormaps into four classes, and the class is chosen by the data rather than by taste:

      
ClassUse it whenExamples
Sequentialthe value has an order and one end mattersviridis, plasma, Blues
Divergingthere is a meaningful middle, and both directions mattercoolwarm, RdBu, PuOr
Cyclicthe value wraps around, like an angle or time of daytwilight, hsv
Qualitativethe categories have no order at alltab10, Set2, petroff10

      
The mistake this taxonomy prevents is using a qualitative palette for an ordered variable, which tells the reader the categories are unrelated when they are a sequence.

      
# Sequential: one ordered variable, colored by how much of it there is.

The older jet and rainbow maps are not, so they invent boundaries where the data has none, and both go light in the middle and dark at both ends, which makes them unreadable in grayscale.

Saving

      
A figure that looks right in a notebook can be unreadable in a document, and the reason is almost always the same: the file was written at the wrong resolution, or in the wrong format.

What happened
      
The three PNGs hold identical information at 9, 28 and 113 kilobytes. The difference is how many pixels the file contains, which decides whether the axis labels survive being printed or projected. 72 is a screen thumbnail, 150 is a reasonable document figure, and 300 is print.

      
The PDF is 9 kilobytes and loses nothing when it is enlarged, because it stores the instructions to draw the figure rather than a grid of pixels.

      

      
Raster and vector

RasterPNG, JPGnoscreens, slides, anything with a photograph in it
VectorPDF, SVG, EPSyesdocuments, print, anything with text in it

      
A figure is mostly text and thin lines, which is exactly what vector formats handle well. Send a PDF to anyone producing a printed report. Use PNG at 150 or higher when the destination needs an image file, and avoid JPG for figures, since its compression smears the edges of text and lines.

Every figure you create stays in memory until it is closed. In a notebook this is usually harmless. In a loop that writes fifty figures to disk, it is not.

def points_drawn(ax):
    """Points with a finite x and y, across every scatter on this Axes.

    len(offsets) is the wrong answer: matplotlib keeps missing values in the
    collection as a masked array and declines to draw them.
    """
    total = 0
    for collection in ax.collections:
        offsets = np.asarray(collection.get_offsets())
        total += int(np.isfinite(offsets).all(axis=1).sum())
    return total
