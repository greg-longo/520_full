Name each file exactly as below (`.png` or `.jpg` both fine). Anything named
correctly gets wired into the page automatically; anything named differently I
will match by hand if you tell me which is which.

| filename | what to capture |
|---|---|

| `difference-tab` | The **Difference** tab, expected value beside submitted value |
| `brightspace-link` | The assignment link in Brightspace that opens CodeGrade |
| `upload-icon` | The upload area in CodeGrade you drag a file onto |
| `windows-find` | File Explorer searching `*.ipynb` (was 2 images — one is fine) |
| `mac-find` | Finder or Spotlight searching for the notebook filename |
| `input-tab-no-arg` | The **Input** tab showing a function called with **no** argument |
| `input-tab-arg` | The **Input** tab showing a function called **with** an argument |
| `check-questions` | A rubric showing `Q1check` / `Q4check` rows |

and leave the rest as placeholders.
