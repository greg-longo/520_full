Glossary

Every term the course expects you to be able to use in a sentence, with the module that introduces it. Same definitions as the flashcards and the notebooks.

Two words are defined twice, and the difference is the lesson rather than an oversight: index is a position in a list and a label on a DataFrame, which is exactly why .loc and .iloc behave differently, and dtype means slightly different things for an array and for a column. Both senses are shown together.
